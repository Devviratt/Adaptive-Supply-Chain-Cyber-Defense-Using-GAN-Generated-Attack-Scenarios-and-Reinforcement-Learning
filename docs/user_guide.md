# User Guide

*This guide will be expanded as features are implemented.*

## Getting Started

1. Follow the [Setup Guide](setup.md) to install and configure the system.
2. Start the backend: `make run-backend`
3. Start the frontend: `make run-frontend`
4. Open the dashboard at `http://localhost:5173`
